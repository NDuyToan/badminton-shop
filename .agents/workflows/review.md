# Review Workflow

1. Inspect git diff/status.
2. Understand the feature and relevant requirements.
3. Read applicable rules.
4. Review correctness first.
5. Review security and authorization.
6. Review database integrity and transactions.
7. Review API contracts.
8. Review Next.js behavior and UX.
9. Review performance.
10. Review tests.
11. Classify findings Critical/High/Medium/Low.
12. Do not edit code unless explicitly asked.

End with a concise release recommendation.
